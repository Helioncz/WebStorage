    Proč to vzniklo

    Tvorba webu nemá být skládačka deseti nástrojů.

    Tvorba jednoduchého webu často znamená řešit složky, repozitáře, editory, preview, deployment, AI chat a verzování zvlášť. Project Hangar to spojuje do jednoho pracovního prostředí.

    01

    Bez ručního zakládání

    Projekt i základní HTML/CSS/JS soubory vzniknou automaticky. Žádné kopírování boilerplate.

    02

    GitHub jedním kliknutím

    Založení repozitáře a nahrání souborů přímo z aplikace. Bez terminálu.

    03

    Live preview při úpravách

    Změny vidíš okamžitě v náhledu vedle souborů. Žádné přepínání oken.

    04

    AI agent vedle kódu

    Placený AI chat agent v pravém panelu, který pomáhá web upravovat za pochodu.

    Jak to funguje

    Od nápadu k webu v šesti krocích.

    1. 1

      Založ projekt

      Zadej název, aplikace vytvoří složku a soubory.

    2. 2

      Vyber šablonu

      Firemní web, portfolio, landing page nebo dokumentace.

    3. 3

      Připoj GitHub

      Repozitář a push jedním kliknutím.

    4. 4

      Upravuj s AI agentem

      Popíš změnu, agent navrhne úpravu kódu.

    5. 5

      Sleduj live preview

      Výsledek vidíš okamžitě vedle editoru.

    6. 6

      Exportuj / publikuj

      Exportuj projekt. Přímý deployment připravujeme.

    Vyzkoušej si workflow

    Vyber šablonu a vygeneruj projekt.

    Šablony jsou stejné jako v aplikaci. Ukázkové demo — simulace výstupu, ne reálná integrace.

        FAQ
        
      Časté otázky.
      
      
      
      
      
        
      Je aplikace zdarma?
      Aplikace samotná je během beta zdarma. AI agent může vyžadovat vlastní placený API klíč podle poskytovatele, kterého si zvolíš.
      
        
      Potřebuji GitHub účet?
      Pro GitHub integraci ano. Bez něj aplikaci použiješ taky — jen bez automatického zakládání repozitáře.
      
        
      Musím umět programovat?
      Nemusíš. Aplikace vytvoří základ a AI agent pomůže s úpravami. Pro pokročilé změny se znalost HTML/CSS hodí.
      
        
      Funguje aplikace offline?
      Tvorba a úpravy projektů fungují lokálně. GitHub push a AI agent potřebují připojení k internetu.
      
        
      Kam se ukládají projekty?
      Lokálně do tvého počítače. Žádný povinný cloud — data zůstávají u tebe.
      
        
      Jak se připojí AI agent?
      V nastavení zadáš API klíč zvoleného AI poskytovatele. Klíč se ukládá bezpečně, ne do kódu projektu.
      
        
      Je potřeba placený AI chatbot nebo API klíč?
      Pro funkce AI agenta ano. Aplikace nepřináší vlastní zdarma AI — napojuje se na placeného agenta dle tvé volby.
      
        
      Půjde aplikace používat i bez AI?
      Ano. Zakládání projektů, soubory, GitHub i live preview fungují i bez zapnutého AI agenta.
