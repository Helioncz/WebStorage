# site-templates/ — knihovna webových šablon

Hotové award-style starter weby. **Jen ke čtení** — needituj je přímo; v Hangaru
si je prohlédneš (panel **Weby → Šablony**), stáhneš jako ZIP, nebo přes **Použít**
vytvoříš editovatelnou kopii do [`../sites/`](../sites/).

| Šablona | Styl |
|---|---|
| `nocturn-studio` | Kreativní agentura — tmavá báze + acid lime, bento grid, kinetic typo, custom kurzor |
| `lumen-editorial` | Editorial / luxury — světlá, serif display, whitespace, terracotta akcent |
| `flux-brutalist` | Brutalismus — stark black/white, neon, raw borders, ticker, mono |
| `prisma-saas` | SaaS landing — gradient mesh + glassmorphism, bento, ceník |

Každá: čistý HTML/CSS/JS (bez frameworku), responzivní, `prefers-reduced-motion`,
random vygenerovaný text. Postaveno podle moderních trendů (awwwards / Base44 / Lovable).

`serve.mjs` = jen lokální náhled.
